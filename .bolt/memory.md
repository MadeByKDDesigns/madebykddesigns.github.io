# Project memory

## Product intent & audience

- Site includes an "apps" page showcasing multiple apps in a card grid with previews, actions, and a support section.
- App-specific content (names, descriptions, images) is placeholder and will be replaced by the user.

## Brand personality & voice

- Production-quality, polished, non-cookie-cutter presentation.

## Visual design & UX direction

- Apps page layout: centered header/title, four-card grid, per-card preview panels, action buttons, and a support section below.
- Tuned aesthetic: compact header, balanced card proportions, refined spacing, softer borders, understated support panel.
- Stack: Vite + React, Tailwind CSS, Lucide React icons, `@/` path alias → `src/`.

## Decisions, constraints & rationale

- Apps page styling/spacing adjusted to match a user-provided reference layout; app content intentionally left unchanged pending next prompt.
- No new UI/icon packages installed.

## Open questions & assumptions

- Correct app names, descriptions, and preview images are expected in the user's next prompt.
- Reference layout proportions are the desired target; further tweaks may follow once real content is supplied.
